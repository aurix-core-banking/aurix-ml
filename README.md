# Aurix ML

Machine learning models and pipelines for the Aurix platform.

## Overview

ML infrastructure for credit scoring, fraud detection, risk analysis, and predictive financial models.

## Tech Stack

- Python / scikit-learn / XGBoost
- MLflow (experiment tracking)
- Apache Spark (feature engineering)
- Docker + Kubernetes (model serving)
